# sistema-vendas-pdv
Sistema web de gestão de estoque e ponto de venda (PDV) com baixa automática de produtos em tempo real. Possui cadastro de itens, alerta de estoque baixo, painel com métricas de faturamento e histórico completo de vendas salvo no navegador via LocalStorage. Simples, rápido e 100% responsivo para rotinas de comércio.
